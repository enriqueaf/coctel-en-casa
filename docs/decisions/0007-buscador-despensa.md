# 0007. Buscador de despensa, no parrilla

Estado: aceptada  
Fecha: 2026-10-30

## Decisión

Un solo campo de búsqueda con modos Todo / Marca / Tipo. Vacío no lista ingredientes. Como mucho ocho sugerencias. Las marcas viven en `data/brands.json`.

## Consecuencias

El formulario escala a cientos de ingredientes sin abrumar.
